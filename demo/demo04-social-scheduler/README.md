> 一份 10 分鐘的簡報，換一整週、每個平台各自寫好的社群內容。

### 為什麼「每平台獨立語氣」是關鍵

一稿多投的排程工具早就存在，客戶不缺那個。他們缺的是「同一件事在四個平台
被講成四種樣子」。本模組把語氣規格寫進 `config.yaml` 與 `prompts/*.md`：

| 平台 | 語氣 | 字元上限 | emoji | hashtag | 一週則數 |
| --- | --- | --- | --- | --- | --- |
| LinkedIn | 專業、長文、產業洞察 | 3000 | 禁止 | ≤ 3 | 5 |
| Instagram | 輕鬆、視覺導向 | 2200 | 3–6 個 | ≤ 8 | 6 |
| X | 簡短、犀利 | **280（硬上限）** | 禁止 | ≤ 2 | 7 |
| Facebook | 親切、社群感 | 2000 | 1–2 個 | ≤ 3 | 5 |

X 的 280 是唯一「做錯就被平台拒收」的規則，所以 `generator.py` 對它的處理是
**先重新生成一次，仍超長才截斷並發出警告**，而不是直接硬切。

## 自主權：為什麼預設是 DRAFT

社群貼文一旦發出就是公開的。撤回一則錯誤貼文的成本，遠高於每週多花 20 分鐘審閱。
因此本模組的預設值是 `DRAFT`——Agent 只產草稿，人按下排程。

想開啟 `SUPERVISED_AUTO`，必須同時滿足：

1. 已在 `DRAFT` 模式穩定運行 **14 天以上**（書中鐵律）
2. `approved_senders` 明確列出可自動排程的平台
3. 客戶書面簽核

`config.yaml` 的 `approved_senders` 在本模組放的是「平台代號」，例如只信任
LinkedIn 自動排程時填 `["linkedin"]`，其餘平台會自動降級回 `DRAFT`。

## 快速上手

```bash
# 離線跑完整流程（零憑證、零網路）
python main.py --mock

# 產出但不發送
python main.py --mock --dry-run

# 推到 Telegram
python main.py --mock --notify telegram

# 串真實 API；缺憑證會明確報錯，不會偷偷退回 mock
python main.py --live

# 跑測試
python -m pytest test_main.py -v
```

### 檔案結構

```
demo04-social-scheduler/
├── README.md          本檔
├── config.yaml        平台 profile、排程時段、字元上限、自主權設定
├── main.py            主流程（載入 -> 產出 -> 自主權標記 -> 通知）
├── generator.py       依 brief 產生各平台內容 + 字元/禁用詞/hashtag 驗證
├── prompts/           四份平台系統提示詞（提示詞是資產，不內嵌在 .py）
│   ├── linkedin.md
│   ├── instagram.md
│   ├── x.md
│   └── facebook.md
├── mock/
│   ├── brief.json         企業主的 10 分鐘簡報
│   └── brand_voice.json   品牌語氣設定
└── test_main.py       3 個測試（happy / X 280 邊界 / _shared 整合）
```

### 客戶要準備的兩份檔案

| 檔案 | 誰填 | 多久 | 內容 |
| --- | --- | --- | --- |
| `brief.json` | 企業主，每週 | 10 分鐘 | 本週主題、促銷、產品重點、禁用詞 |
| `brand_voice.json` | 導入時一次填完 | 30 分鐘 | 品牌定位、語氣支柱、3–5 則真實貼文範例、招牌 hashtag |

`brand_voice.json` 的 `tone_examples` 少於 3 則會觸發 AMBER 警告。
語氣範例是這個模組品質的天花板——範例不足，產出就會飄。

## Client Pitch 話術

> 「只需您 20 分鐘的時間——一整週的社群內容就已為每個平台撰寫、格式化並排程完畢。

### 展開版（三分鐘電話）

1. **戳痛點**：「你上次社群斷更是什麼時候？多半不是因為沒想法，是因為那週太忙。」
2. **給對比**：「現在是每週 5 到 8 小時。之後是 10 分鐘填表、20 分鐘審稿。」
3. **拆疑慮**：「AI 會不會亂寫？預設不會直接發。所有內容都是草稿，你按下排程才會出去。
   前兩週我們一定跑草稿模式，你確認語氣對了，才討論要不要放寬。」
4. **給價格**：「$350 建置、$90 月費。以你每小時的價值算，第一週就回本了。」
5. **收尾**：「這禮拜給我 10 分鐘填一份簡報，我先做一週給你看，你再決定。」

## 已知限制

- **視覺素材不在範圍內**。本模組產文案與視覺需求說明，不產圖片。
- **排程 API 未串接**。目前輸出的是帶建議時段的草稿清單，實際推送到各平台的
  排程器（Buffer / Later / Meta Business Suite）需另行整合。
- **`--mock` 模式的貼文是離線組稿**。`LLMClient` 在 mock 下只回傳佔位字串，
  `generator.compose_offline_post()` 會改用 brief 素材組出可讀貼文，
  好讓你看到的是排程流程而不是一堆 `[MOCK]`。真實文案品質要跑 `--live` 才準。
